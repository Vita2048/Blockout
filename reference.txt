🎮 QUICK START
─────────────────────────────────────────────────────────────────────────────
1. Open index.html in a web browser
2. Watch blocks fall from the top
3. Use arrow keys to move left/right
4. Use Q/W/E to rotate
5. Press SPACE to drop
6. Fill complete horizontal layers to score points

═══════════════════════════════════════════════════════════════════════════════

⌨️ KEYBOARD CONTROLS
─────────────────────────────────────────────────────────────────────────────
MOVEMENT:
  Arrow Up (↑)    = Move forward
  Arrow Down (↓)  = Move backward
  Arrow Left (←)  = Move left
  Arrow Right (→) = Move right

ROTATION:
  Q = Rotate around X-axis (tilt)
  W = Rotate around Y-axis (spin)
  E = Rotate around Z-axis (roll)

SPECIAL:
  Space = Hard drop to bottom
  P     = Pause / Resume
  R     = Restart game

═══════════════════════════════════════════════════════════════════════════════

🎯 GAME OBJECTIVE
─────────────────────────────────────────────────────────────────────────────
1. Arrange falling blocks to complete horizontal layers
2. Full layers clear automatically and earn points
3. Stack blocks without reaching the top
4. Higher levels = faster speed + more points
5. Beat your high score

═══════════════════════════════════════════════════════════════════════════════

📊 SCORING
─────────────────────────────────────────────────────────────────────────────
Block Placement:  10 × (block size) × level
Layer Clear:      100 × (layers cleared)² × level

Examples:
  4-cube block at level 1   = 40 points
  1 cleared layer           = 100 points
  2 cleared layers          = 400 points
  2 cleared layers at level 5 = 2000 points

⬆️ DIFFICULTY LEVELS
─────────────────────────────────────────────────────────────────────────────

💡 TIPS & STRATEGIES
─────────────────────────────────────────────────────────────────────────────
1. Plan ahead - blocks fall from the top center
2. Use rotation creatively to fit odd shapes
3. Try to clear multiple layers at once for big bonuses
4. Build up from the sides, fill center last
5. Higher levels give exponentially more points
6. Focus on completing layers, not just stacking blocks
7. Watch the falling speed - it increases with level
8. Use hard drop (space) when falling is too slow

🐛 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────
Game won't load:
  → Check internet connection (needs Three.js CDN)
  → Try different browser
  → Check browser console (F12) for errors

Can't move blocks:
  → Click in game area to focus window
  → Check CAPS LOCK isn't on
  → Try arrow keys instead of WASD

Game is slow:
  → Close other browser tabs
  → Check system load
  → Try different browser (Chrome usually fastest)

High score disappeared:
  → Browser data was cleared
  → Try different browser profile
  → Check localStorage not disabled
